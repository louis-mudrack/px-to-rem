# See your progress

The **PX to REM** view in the Explorer lists files that still use px and the share of lengths that already scale.

The **value audit dashboard** shows:

- every spacing, size, font-size and radius value in use, with off-grid outliers highlighted
- how much of your spacing sits on a 4px or 8px grid
- which modular type scale your font sizes follow
- a proposed set of design tokens, ready to export as CSS, Sass, Less, Stylus, Tailwind v4 or W3C design tokens
